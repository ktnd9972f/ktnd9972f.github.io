本サイトについて

UTATYPE（ウタタイプ）は、歌に合わせて歌詞をタイピングする、個人制作のファンゲームです。楽曲・歌詞・動画の権利は、それぞれの権利者に帰属します。

動画について

本サイトでは YouTube で公開されている動画を、YouTube の埋め込みプレーヤー（YouTube API サービス）で再生しています。本サイトは動画や音源を保存・配布していません。本サイトを利用することで、YouTube 利用規約およびYouTube API サービス利用規約に同意したものとみなされます。

記録と個人情報について

スコアなどの記録や設定は、お使いのブラウザの中にだけ保存され、外部のサーバーには送信されません。また、ブラウザのプライベートモードを利用している場合、記録や設定は保存されない場合があります。

動画の再生には YouTube API サービスを利用しており、YouTube（Google）が Cookie などの情報を取得する場合があります。詳しくは Google のプライバシーポリシーをご確認ください。

免責事項

本サイトの利用により生じたいかなる損害についても、制作者は責任を負いません。動画が削除・非公開になった場合や、埋め込みが制限された場合、通信の状況などによっては、再生できない、または歌詞のタイミングがずれる場合があります。本サイトの内容は予告なく変更し、公開を終了することがあります。
